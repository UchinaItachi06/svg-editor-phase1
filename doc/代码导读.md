# SVG 编辑器代码导读

本文由助手根据实际代码整理，用于解释设计与帮助学生复核，不代表学生已经独立完成分析或答辩。

## 从 delete node 看 Command 模式

1. cli/Tokenizer 把输入拆成命令名和参数，cli/CommandRouter 的 delete 处理项创建 DeleteCommand('node')。
2. application/Session.execute 调用 EditCommand.execute(currentDocument)。
3. EditCommand 先 clone 当前文档为 draft，再把 draft 交给具体命令的 apply。
4. DeleteCommand.apply 用 Document.require 查找目标，再调用 detach。删除的是整个子树引用，因此子孙一起从文档消失。
5. apply 成功后，EditCommand 保存 before 与 after 的深拷贝，Session 替换当前文档并让 History.record 记录该命令。
6. undo 时 History 取出上一条命令，调用它的 undo，得到 before 的新深拷贝；Session 将其设为当前文档。redo 使用 after。

代码入口：[命令分发](../src/cli/CommandRouter.ts)、[编辑命令基类](../src/commands/EditCommand.ts)、[删除命令](../src/commands/DeleteCommand.ts)、[当前会话](../src/application/Session.ts)、[历史记录](../src/application/History.ts)。

Command 负责把一次编辑封装成对象，Memento 是本项目支持撤销的快照实现选择。二者作用不同；Command 本身不限定必须采用全量快照。

## 为什么命令失败不会修改画布

EditCommand.execute 的顺序是“复制当前文档 → 修改副本 → 返回结果”。Session 只有在 execute 正常返回后，才替换当前文档并记录历史。

重复 id、非法缩放或循环归属会在 draft 上抛出异常。异常返回到 CLI 形成 error: 输出；替换文档和记录历史都没有发生。所以不会出现“先删掉一部分图形，再报错”的半完成状态。成功的新编辑会清空 redo，失败命令不会。

学生实际验证了三种失败后的 tree 不变；自动测试还覆盖了容器部分移动时出现数值溢出的情况。

## 为什么矩形与文字会一起移动

[Shape](../src/model/Shape.ts) 是共同抽象，规定 move、scale、clone 等行为。[Group](../src/model/Group.ts) 内部持有 Shape 类型的有序子节点。

Group.move 不关心每个子节点究竟是矩形、文字还是嵌套容器，只调用 child.move(dx, dy)。矩形通过 GeometryShape 修改 x/y；文字修改自己的 x/y；嵌套容器再向下递归。这是 Composite 的统一操作与多态。

Group 的样式属性写在 SVG 的 g 元素上，按 SVG 继承生效。set g fill 不会强行覆盖子图形已经显式设置的 fill。

## 为什么保存后不能撤销

成功 save 后 Session.saved 调用 History.barrier，清空过去与未来的记录，并将 blocked 设为 true。undo 和 redo 检查到屏障会按要求报错。

下一条成功编辑进入 History.record 后，blocked 解除，但只能访问这次编辑之后的历史。查询 tree/show/help 不记录历史；canvas 查询不设屏障，修改尺寸会设屏障。

## 模块依赖如何理解

- model 提供图形与文档行为，不认识 CLI、文件或具体编辑命令。
- commands 描述编辑动作，只依赖模型和命令抽象。
- application 管理当前文档与历史，并定义 DocumentStore 接口。
- cli 负责输入适配和输出，通过 DocumentStore 接口请求读写。
- infrastructure 实现接口并负责 XML 与文件；main 把具体实现注入 CLI。

架构规则写在 [作业主文档](README.md)，[架构测试](../test/architecture.test.ts) 自动检查相应导入方向、一类一文件和类文件同名。

## 哪些地方以后可能变化

| 变化 | 当前实现与取舍 |
|---|---|
| 新图形 | Shape 多态与工厂集中，但工厂仍需修改；后续改为提供者注册 |
| 新命令 | 新建具体 EditCommand，分发仍集中在 CommandRouter，待改为注册 |
| 新界面 | 模型、命令与 Session 可复用；CLI 中的用例协调需再抽离 |
| 大文档 | 全量快照验证容易，但耗时和内存随文档与历史增长；可改局部快照或增量并限制历史容量 |
| 更广 SVG | 当前只支持明确子集，transform 等输入会拒绝；需要根据教师范围继续扩展 |

## 可以据实说明的验收结论

61 项自动测试通过，学生实际运行了创建、移动、撤销重做、保存屏障、三类错误输入和子树删除恢复。记录支持这些已检查场景正确，不构成对全部 SVG 标准或所有输入的证明。

作业明确要求六种类型、Command、面向对象及远程开发历史；box 属于后续阶段。transform 出现在背景示例中，当前实现未覆盖，应确认教师的读入兼容范围。不得把尚未实现的能力写成已完成。
